# InternetEnabler

Простой инструмент для домашних обязанностей: интернет на компьютере сына
отключается по расписанию (или вручную с родительского компьютера) через
правило Windows Firewall. Включить обратно можно одним кликом на иконку в
трее — это осознанное действие, отмазка "забыл" не работает.

Оба компьютера должны быть в одной локальной сети. Родительский компьютер
может достучаться до компьютера сына, поэтому вся коммуникация идёт
"сервер → клиент": сервер отправляет команды клиенту.

## Как это работает

- **client** — работает на компьютере сына. Автозапускается при входе в
  систему с правами администратора (через Scheduled Task, без UAC-окна
  каждый раз). Блокирует исходящий интернет-трафик через Windows Firewall,
  но не трогает трафик внутри локальной сети — сервер продолжает достучаться
  даже когда интернет заблокирован. Иконка в трее (красная = заблокировано,
  зелёная = ОК) с кнопкой "Enable Internet".
- **server** — простой CLI на родительском компьютере, отправляет команды
  клиенту по HTTP (защищено общим секретным токеном).

## Установка

### 1. Клиент (компьютер сына)

Нужен установленный [Python 3](https://www.python.org/downloads/).

```powershell
cd client
copy config.example.json config.json
notepad config.json   # впиши token и lan_subnet (например 192.168.1.0/24)
```

Запусти `install.ps1` **из PowerShell от имени администратора** — это
создаст правила фаервола и задачу автозапуска:

```powershell
.\install.ps1
```

Скрипт сам поставит зависимости (`pystray`, `Pillow`), настроит автозапуск
и сразу запустит агента.

### 2. Сервер (твой компьютер)

```powershell
cd server
copy config.example.json config.json
notepad config.json   # тот же token, client_host = IP компа сына, client_port = 5987
```

IP компьютера сына лучше зафиксировать через резервацию DHCP на роутере,
чтобы он не менялся.

## Использование

```powershell
python server.py status
python server.py block
python server.py unblock
python server.py set-schedule 20:30 21:00
python server.py set-schedule --clear
```

`set-schedule` задаёт время (может быть несколько), в которое клиент сам
включит блокировку — работает даже если твой компьютер выключен.

## Важные детали

- Токен (`token` в config.json) должен совпадать на клиенте и сервере —
  это единственная защита от посторонних команд по локальной сети.
- Если у клиента и сервера разные подсети/VLAN, `lan_subnet` в
  `client/config.json` нужно указать правильно, иначе после блокировки
  сервер тоже не достучится до клиента.
- Это семейный инструмент на доверии, а не защита от технически подкованного
  подростка: доступ администратора на своём компьютере всё равно позволяет
  снять правила фаервола или остановить агента через диспетчер задач.
